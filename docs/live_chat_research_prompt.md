Ты — эксперт по инструментам клиентской поддержки, live chat виджетам для сайтов и интеграциям с CRM/LLM. Проанализируй запрос пользователя и дай полный, структурированный ответ.
Основная задача
Найди полный список бесплатных (или с хорошим free tier) приложений/виджетов для live chat на сайте, чтобы посетители могли сразу писать сообщения клиентам. Сравни их по ключевым критериям, включи отзывы из интернета (G2, Capterra, Trustpilot, Reddit и т.д. на 2026 год), условия free tier, ограничения и возможности масштабирования.
Обязательно добавь в сравнение: Tawk.to, Tidio, Crisp, Chatwoot, HubSpot Live Chat. Добавь в сравнение tiledesk (self-hosted), freshchat. Рассмотри также открытые/self-hosted варианты (например, Chatwoot). В шорт лист для сравнения добавляй только те, у которых есть бесплатный тариф!
Ключевые критерии сравнения (найди/выведи их из исследований и структурируй таблицу)
•  Ценообразование (free tier): Что бесплатно навсегда, лимиты (кол-во чатов/агентов/сайтов), переход на платное, скрытые платежи.
•  Установка и кастомизация: Простота внедрения на сайт (WordPress, Shopify, чистый HTML и т.д.), брендирование виджета.
•  Начало чата: Возможность настроить так, чтобы пользователь сразу мог задать вопрос без обязательного сбора имени/email (критично важно — пользователь ненавидит преграды).
•  Мобильность для владельца: iOS-приложение (iPhone), интеграция с Telegram/WhatsApp для ответов с телефона (без ПК).
•  Мультипроектность: Возможность управлять 3+ проектами/сайтами из одного аккаунта/приложения.
•  AI/Автоматизация и LLM:
	•  Встроенный AI-бот или классификатор (часть вопросов отвечает робот).
	•  Возможность интеграции с ИИ API (например, DeepSeek), свой классификатор (RAG) и собственной локальной LLM (с 12 ГБ RAM — оцени реалистичность, риски зависаний, рекомендации по лёгким моделям/классификаторам вроде Llama 3 8B, quantization и т.д.).
•  Мониторинг и WebView: Возможность видеть действия пользователя на сайте (visitor tracking, screen sharing/WebView для просмотра экрана клиента в одном из проектов).
•  Интеграции с CRM: Особенно Zoho (есть почта) и HubSpot. Как сочетается с ними.
•  Дополнительно: Отзывы (плюсы/минусы), надёжность, безопасность, мультиязычность, proactive чаты, аналитика.

1.  Краткий обзор топ-решений (5–8 лучших) с рекомендацией №1 для сценария пользователя.

3.  Подробный разбор каждого ключевого инструмента (free tier + соответствие специфическим нуждам).
4.  Рекомендации по LLM-интеграции (локальная + классификатор, hardware constraints 24 ГБ RAM).
5.  Как настроить “мгновенный чат” без форм.
6.  Решения для multi-project и мобильного ответа.
7.  Потенциальные риски и альтернативы (self-hosted open-source).
