# Промпт для сессии Claude Code на компьютере владельца (бэклинки через Chrome)

Скопируйте всё, что ниже линии, в новую сессию Claude Code на своём компьютере.
Запускать так: `claude --chrome` (Chrome открыт, расширение Claude in Chrome
≥ 1.0.36 установлено и залогинено тем же аккаунтом Anthropic; вход в Claude
Code — через `/login`, не через API-ключ).

---

Ты работаешь в моём настоящем Chrome через расширение Claude in Chrome. Задача —
**успешно зарегистрировать сайт Horizance VPN (https://horizancevpn.com) минимум
на двух площадках-каталогах**, чтобы получить обратные ссылки. Отвечай мне
по-русски.

## Откуда брать данные

Кодовой базы у тебя нет, она на моём сервере. Подключайся по SSH и только
**читай** файлы (ничего там не меняй, кроме одного файла отчёта, см. ниже):

```
ssh -p 9753 pashavpsadm@193.233.127.32
```

Пароль/ключ спроси у меня, если SSH его попросит. Нужные файлы в
`/home/pashavpsadm/horizance_vpn_bot/`:

- `backlinks_vpn_field_templates.md` — **готовые тексты для всех полей форм**
  (название, описания короткое/длинное на русском и английском, цены,
  платформы, юрлицо, логин/пароль для регистраций, email). Бери тексты ТОЛЬКО
  оттуда, ничего не придумывай: цифры и формулировки там сверены с кодом.
- `build_backlinks_xlsx.py` — таблица целей со статусом и заметками по каждой
  площадке (почему прошлые попытки не удались). Прочитай перед началом.

Например: `ssh -p 9753 pashavpsadm@193.233.127.32 'cat ~/horizance_vpn_bot/backlinks_vpn_field_templates.md'`.

## Правила (обязательно)

- Email для регистраций: `james.smith.web@gmail.com`. Логин и пароль — из
  `backlinks_vpn_field_templates.md` (одинаковые везде).
- **Никакого телефона.** Если площадка требует номер телефона или платный
  тариф — прекращай на ней, запиши причину, переходи к следующей.
- Капча/проверка «я не робот»: попробуй пройти; если не выходит за 2–3 попытки,
  попроси меня пройти её вручную в этой вкладке и жди.
- Письма подтверждения ищи в Gmail (в этом же Chrome), переходи по ссылке
  подтверждения. Ничего, кроме писем от этих площадок, в почте не открывай.
- Тон текстов: без сленга и бахвальства, без слов про обход DPI/«не палится»,
  не обещать «работает без приложения». Только тексты из шаблонов.
- Логотип — только настоящий файл с сайта (https://horizancevpn.com, фавиконка
  или логотип целиком). Не рисовать и не генерировать свой.
- Работай в новых вкладках, мои открытые вкладки не трогай, в конце закрой свои.
- Не кликай «удалить»/«отменить» и прочее, что вызывает диалоги подтверждения.
- Если что-то непонятно или площадка просит данные, которых нет в шаблонах
  (например, число сотрудников или выручку), — спроси меня, а не выдумывай.
